# Семейный магазин Корзинки — Telegram-бот с веб-аппом

## Что изменилось по сравнению с прошлой версией

- **Реальные товары.** Раньше `api.korzinka.uz/search/` отдавал только слова-подсказки
  для поиска, а не товары — карточки не могли отрисоваться. Теперь бэкенд берёт
  данные из `catalog.korzinka.uz/api/catalogs/categories` — там настоящие товары
  с фото, ценой, скидкой и весом.
- **Свой backend вместо прямого фетча из браузера.** `index.html` больше не ходит
  в korzinka.uz напрямую (там могли быть проблемы с CORS) — вместо этого он
  обращается к твоему же боту (`/api/categories`, `/api/products`), а бот сам
  сходил в Корзинку, обработал и закэшировал данные на 10 минут.
- **Бот принимает заказ.** Раньше `tg.sendData()` в вебапе отправлял данные,
  но бот их не читал. Теперь есть обработчик `F.web_app_data`, который красиво
  показывает заказ пользователю (и опционально — админу).
- **Карточка товара.** У Корзинки нет отдельного API с описанием/составом товара
  (сайт вообще не показывает карточки — сразу уводит в приложение), поэтому
  карточка собрана из тех же данных, что в списке: крупное фото, полное
  название, цена, скидка, вес.
- **Токен бота** теперь берётся из переменной окружения, а не лежит в коде.
  **Обязательно отзови старый токен через @BotFather** (он был в файле, который
  ты мне прислал) и создай новый.

## Важно про сам домен для веб-аппа

Telegram WebApp **обязательно** требует публичный HTTPS-адрес — localhost не
подойдёт, даже для тестов. Варианты:

1. **Быстрый тест:** подними туннель, например `ngrok http 8080` или
   `cloudflared tunnel --url http://localhost:8080`, и используй выданный
   HTTPS-адрес.
2. **Постоянный вариант:** задеплой на любой хостинг с доменом и SSL
   (VPS + nginx, Railway, Render и т.п.), пробрось порт 8080 наружу через
   reverse proxy.

## Запуск

```bash
pip install -r requirements.txt

export BOT_TOKEN="твой_новый_токен_от_BotFather"
export WEBAPP_URL="https://твой-публичный-адрес"   # см. выше
export ADMIN_CHAT_ID=""                              # необязательно

python main.py
```

Бот и веб-сервер (порт 8080 по умолчанию, можно поменять через `PORT`)
запускаются в одном процессе.

## Структура

```
main.py           — бот (aiogram) + веб-сервер (aiohttp) + прокси к API Корзинки
web/index.html    — сам веб-апп (каталог, категории, карточка, корзина)
requirements.txt
```

## Что можно доработать дальше

- Данные сейчас берутся из промо-подборок Корзинки (акции недели, школьный
  базар и т.д.) — это не полное дерево "все категории магазина". Если найдёшь
  запрос с полным каталогом разделов — пришли, подключим.
- Добавить постоянное хранилище заказов (сейчас заказ просто пересылается
  в чат, но нигде не сохраняется).
- Добавить количество товара с шагом веса (кг) для весовых позиций.
